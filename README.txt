Playback:
- Hero Enter button and main Play button start Live Radio.
- Native HTML5 audio; no YouTube, no HLS.js and no service worker.
- Direct HTTPS MP3 live feeds are configured for Shiva, Bhakti Sangeet, Hanuman, Krishna, Devi Maa and Kirtan.
- If one source fails/stalls, the player tries other configured sources.
- Tap once because browser autoplay policies require user interaction before audio.
- Continuous playback lasts while the visitor keeps the page open.
