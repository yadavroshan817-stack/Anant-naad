Playback source

Reference-style radio architecture, kept transparent.

Why this player exists: the reference site uses YouTube as the media delivery layer instead of hosting the recordings itself. Anant Naad uses the official YouTube IFrame Player API for its music source, while the Anant Naad interface controls the experience around it. This means a large catalogue can be played without storing commercial MP3s on your GitHub Pages site. YouTube can still control ads/recommendations and embeddability; the site does not override those platform rules.
